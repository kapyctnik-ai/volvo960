# Volvo 960 Actuators

Android-приложение для ручного управления актуаторами Volvo 960 (1996, ISO 9141-2)
через дешёвый Bluetooth-адаптер ELM327 v1.4b (Bluetooth Classic / SPP).

## Статус

Первая полная сборка архитектуры (транспорт, реестр, hold-repeat, UI) реализована
целиком за один заход, без реального железа и без Android SDK в среде разработки —
**сборка (`./gradlew assembleDebug`) и запуск на устройстве ещё не проверялись**.
Перед первым выездом к машине обязательно соберите и прогоните приложение хотя бы
на телефоне без адаптера (экран консоли покажет "нет соединения" — это ожидаемо).

## Архитектура

```
transport/   Elm327Transport — Bluetooth-сокет, единая mutex-очередь команд,
             автопереподключение, ConnectionState как StateFlow.
             НЕ трогать при добавлении новых актуаторов.

data/        Actuator (Room-сущность) — реестр актуаторов. Новый узел машины =
             новая запись в БД, не новый код.

service/     HoldManager — параллельные hold-repeat циклы поверх общей очереди
             транспорта; глобальный watchdog 30 с без ответа.
             HoldService — foreground-сервис, WAKE_LOCK, уведомление со списком
             активных удержаний и кнопками "стоп" на каждое.

ui/main/     Главный экран: статус подключения, активные удержания, реестр.
ui/console/  Консоль сырых команд — инструмент подбора новых актуаторов,
             логирует весь трафик в файл, "Сохранить как актуатор".
ui/editor/   Форма создания/редактирования записи реестра.
```

`VolvoApp` (Application) держит все синглтоны (`transport`, `holdManager`,
`repository`, `notificationHelper`) — они переживают отдельные Activity и продолжают
работать в фоне даже без открытого экрана.

## Как подобрать новый актуатор

1. Подключитесь к адаптеру на главном экране (адаптер должен быть уже
   сопряжён в настройках Bluetooth Android — сканирование в самом приложении
   не делается).
2. Откройте «Консоль команд», пробуйте байты вручную.
3. Как только команда сработала — «Сохранить как актуатор», укажите имя и
   тип поведения (разово / удержание).
4. На главном экране появится карточка с тогглом (удержание) или кнопкой
   (разово).

## Сборка

Нужен Android SDK (compileSdk 34) и подключение к `google()`/`mavenCentral()` —
в среде, где писался код, доступа к `dl.google.com` не было, поэтому
`./gradlew assembleDebug` тут не запускался. Обёртка Gradle (8.7) уже
сгенерирована и закоммичена.

```
./gradlew assembleDebug
```

minSdk 26 (Android 8), стек: Kotlin, Room (KSP), coroutines, обычные Android
Views + ViewBinding, минимум зависимостей.
