# Промпт для генерации ассетов кластера Volvo 960

Нужен набор изображений для фотореалистичной реплики приборной панели
Volvo 960 (1995–1997, дорестайл, европейский рынок, км/ч).

Отдавать **отдельными слоями**, иначе стрелки нельзя анимировать.

---

## Что именно нужно (5 файлов)

### 1. `cluster_face.png` — статичный фон, БЕЗ стрелок

Разрешение 4096×1400, прозрачный фон вокруг корпуса, PNG-24.

Фотореалистичный рендер лицевой части приборного щитка Volvo 960 в
ночной подсветке. Строго фронтально, перпендикулярно плоскости щитка,
без перспективы, без наклона, без бликов объектива и без искажения краёв.

Слева направо:

1. **Указатель топлива** — частичная круглая шкала, обрезанная левым краем
   корпуса. Центр окружности уходит за левый край кадра, видна только
   правая часть дуги. Разметка: короткая дуга с делениями, буквы `E` и `F`,
   пиктограмма топливной колонки.
2. **Часы** — полный круг. Цифры `12`, `3`, `6`, `9`, между ними по два
   штриха. Без секундной разметки.
3. **Спидометр** — самый крупный круг, по центру щитка. Одна шкала:
   - **км/ч**, `0…240`, крупные цифры через 20, штрихи через 10.
     Шкалы mph нет вообще, вторую шкалу не рисовать.
   - Окно одометра: горизонтальное прямоугольное окошко **выше центра**,
     6 знакомест, механические барабанные цифры, белые на чёрном, с
     тонкими вертикальными перегородками между барабанами.
   - Окно суточного пробега: меньшее окошко **ниже одометра**, 4 знакоместа,
     последний барабан отделён и обычно белого/иного оттенка.
   - Подпись `km/h` мелко под окошками.
4. **Тахометр** — круг, чуть меньше спидометра. Шкала `0…7`, подпись
   `×1000 r/min` внизу справа внутри циферблата. Красная зона от 6 до 7
   тонкой дугой у самого обода.
5. **Указатель температуры ОЖ** — частичная круглая шкала, зеркально
   топливной, обрезанная правым краем корпуса. Буквы `C` и `H`,
   пиктограмма термометра в жидкости, красный сегмент у горячего конца.

Оформление:

- Корпус щитка — матовый тёмно-серый пластик с очень мелкой шагренью,
  почти чёрный, слегка светлее циферблатов.
- Циферблаты утоплены, у каждого свой кольцевой ободок с мягкой
  внутренней тенью по верхней кромке.
- Подсветка **зелёно-циановая** (примерно `#7FF2F4`), мягкое свечение
  вокруг цифр и штрихов, лёгкий ореол на соседнем пластике.
- Стекло: едва заметный вертикальный градиент отражения, без резких
  бликов, не перекрывает разметку.
- Ряд контрольных ламп внизу **не рисовать вообще**.
- Стрелок **нет**. Осей и втулок в центре **нет** — они отдельным слоем.

### 2. `needle_long.png` — стрелка для спидометра, тахометра и часов

512×512, прозрачный фон. Стрелка нарисована **вертикально вверх**, точка
вращения — ровно в центре изображения (256, 256). Кончик почти касается
верхнего края, хвостовик заходит за центр примерно на 12% длины.

Оранжево-красная (`#FF5A1A`), к кончику чуть светлее, тонкая, с плавным
сужением. Под стрелкой мягкая тень на циферблат. Собственное свечение
слабое.

### 3. `needle_short.png` — стрелка для топлива и температуры

512×512, та же геометрия и цвет, но короче и толще пропорционально.

### 4. `needle_second.png` — секундная стрелка часов

512×512, та же геометрия. Очень тонкая, длиннее минутной, с маленьким
противовесом на хвостовике.

### 5. `hub.png` — центральная втулка

256×256, прозрачный фон. Тёмная матовая шайба с фаской и слабым бликом
сверху, ложится поверх основания стрелок.

---

## Обязательные требования

- Все пять файлов — **строго в одном масштабе и в одной геометрии**.
- Никакого текста, кроме того, что есть на настоящем щитке.
- Никаких водяных знаков, подписей, рамок.
- Никакой перспективы: только фронтальная ортогональная проекция.
- Фон вокруг корпуса — прозрачный, не белый и не чёрный.

## Дополнительно (чтобы стрелки встали точно)

Нужен `cluster_geometry.json` с координатами в пикселях относительно
`cluster_face.png`:

```json
{
  "fuel":  { "cx": 0, "cy": 0, "r": 0, "startAngle": 0, "sweepAngle": 0 },
  "clock": { "cx": 0, "cy": 0, "r": 0 },
  "speedo":{ "cx": 0, "cy": 0, "r": 0, "startAngle": 0, "sweepAngle": 0,
             "odometerRect": [0,0,0,0], "tripRect": [0,0,0,0],
             "resetKnob": { "cx": 0, "cy": 0, "r": 0 } },
  "tacho": { "cx": 0, "cy": 0, "r": 0, "startAngle": 0, "sweepAngle": 0 },
  "temp":  { "cx": 0, "cy": 0, "r": 0, "startAngle": 0, "sweepAngle": 0 }
}
```

`startAngle` — угол минимума шкалы, `sweepAngle` — угол до максимума,
в градусах, 0° = направление вправо, положительное направление — по
часовой стрелке.
